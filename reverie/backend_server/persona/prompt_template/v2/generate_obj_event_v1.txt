Task: Describe the current state of an object that is being used by someone.

Rules:
1) Output ONLY ONE short sentence. No explanations. No "Let's think". No "Step 1/2". No extra lines.
2) The sentence MUST start with the object name and the word "is" (format: "<object> is ...").
3) Keep it concrete and physical when possible (e.g., "is being heated", "is running with water", "is being used to write email").
4) Do NOT include the person's name in the output.
5) Do NOT use quotes or markdown.

Examples:
Input:
Object: oven
Persona: Sam Johnson
Event: eating breakfast at/using the oven
Output:
oven is being heated to cook breakfast.
---
Input:
Object: computer
Persona: Michael Bernstein
Event: writing email at/using the computer
Output:
computer is being used to write email.
---
Input:
Object: sink
Persona: Tom Kane
Event: washing his face at/using the sink
Output:
sink is running with water.
